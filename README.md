# 🚚 Controle de Carrinhos

Sistema simples para registrar **saída e devolução de carrinhos de entrega**.

## ✨ Funcionalidades
- Registro de saída com nome e até 2 carrinhos.
- Registro automático da data/hora de saída.
- Botão para marcar retorno, registrando data/hora.
- Histórico de entregas concluídas.

## 🚀 Como rodar
1. Baixe o projeto ou clone do GitHub.
2. Abra o arquivo `index.html` no navegador.
3. Para publicar:
   - Envie para um repositório no GitHub.
   - Conecte ao [Netlify](https://www.netlify.com/).
   - Ele gerará um link para acessar o sistema online.
